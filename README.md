# Sistema de Validação de Senhas

Projeto desenvolvido em Python para uma atividade da faculdade, utilizando estruturas de repetição `for` e `while`.

## Sobre o projeto

O programa realiza o cadastro de 5 funcionários e valida as senhas informadas.

A senha só é aceita quando:
- a confirmação estiver correta;
- possuir pelo menos 6 caracteres.

## Estruturas utilizadas

- `for` → utilizado para repetir o cadastro dos funcionários;
- `while` → utilizado para validar a senha até que esteja correta;
- `if` → utilizado para verificar as condições da senha.

## Tecnologias

- Python 3
